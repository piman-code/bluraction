# 구현·검증 상태

2026-10-02 개발 중간 기록이다. 전체 Mac·Windows 공개 목표는 미완료이며 GitHub 새 소스/릴리스를 배포하지 않았다. 운영 Mac은 0.7.2/build18 그대로다. 새 Mac 소스 후보는 0.8.0/build19, Windows 소스는 0.8.0.dev1이다.

이 문서의 QA 경로는 비공개 로컬 증거 참조다. 전체 QA·빌드·백업·사용자 원본을 공개 저장소에 포함하지 않는다. 공개 검수 자료는 합성 파일과 필요한 결과만 별도로 선별하고 경로·민감정보를 검토해야 한다.

현재 증거 폴더는 `qa-20261001/cross-platform-planning-20261002/`다. 다음은 초기 구현의 역사 기록이며 후속 현재 결과는 아래에 구분한다. macOS arm64에서 Windows 어댑터의 엔진39·미디어/파일 안전성21·Qt grapheme11·IO cancellation5·shared16·공통 PDF 기하4 검사가 통과했다. 숫자 기반 raw PDF 정책6과 fake HEIF 정책9도 통과했지만 실제 pypdf7 검사와 실제 HEIC2 검사는 backend 부재로 미검증이다. pypdf 로그의 class-level skip 하나는 그 아래 실제7 검사가 실행되었다는 뜻이 아니다. 당시 PyAV/OpenCV 영상9 검사는 미실행이었다. 현재는 실제 표시 PTS 탐색·EOF/취소 검사를 추가해10개이며 의존성이 없어 미실행이다.

속성 패널은 바꾼 필드만 수정하며, 가리기 영역·그림 혼합 선택에서 각 종류에 맞는 필드만 적용한다. 큰 효과 값과 소수 굵기·채우기 보존, 혼합 선택 후 실행취소·저장/재열기를 추가 검증했다. `qt-mixed-style-regression79.log`의 엔진39·Qt UI35·IO5는79건 통과다. 이후 패널의 가로 잘림을 WrapLongRows와 글꼴 메뉴 최소 폭으로 수정하고 offscreen 렌더링을 확인했다. 실제 Windows 화면 검증을 뜻하지 않는다.

비동기 열기·프로젝트 재연결·템플릿 준비·저장은 QThread 후보 준비 후 GUI에서 확정하도록 연결했다. 성공 전에는 현재 workspace/cache/history를 보존하며 취소·실패·늦은 결과에서 확정하지 않는다. 초기 UI34 실행은 템플릿 경로 캡처 결함 및 완료 콜백 Mock의 스레드 하네스 문제로 실패했다(`qt-ui-async34.log`). 수정 후 영향 검사2와 전체34가 통과했다(`qt-ui-async34-fixed.log`: exit0, 1.202초). 실제 QThread·QtPdf·출력 경로 및 합성 비디오 세션/콜백을 검사했으며 실제 영상 코덱 재생 검증은 아니다. 이 실행은 macOS의 offscreen Qt 검사다. 과거 UI27/30 통과와 구분하며 실제 Windows native UI 통과라고 표시하지 않는다.

Mac의 `mac-regression130.json`은 첫 프레임 수리 **이전 소스**에 대한18묶음130 통과 증거다. 이후 메타데이터는 정상이나 첫 프레임은 손상된 영상이 기존 dirty 편집을 교체하는 반례를 확인하여 수리했고, 후속 `mac-first-frame-portable25.log`의25 검사가 통과했다. 두 결과를 합쳐 현재 소스 전체155 통과로 주장하지 않는다. 이전 후보·ZIP/DMG도 현재 수리의 검증된 최종 패키지로 간주하지 않는다. 첫 프레임 수리 후 영상 관련9묶음51건도 통과했다(`mac-first-frame-related-regression.log`). 이후 독립 검토에서 Mac의 색 변경이 기존 소수 굵기·채우기를 바꾸는 문제를 찾아 필드별 갱신으로 수정했고, 후속 WorkspaceBoundary9건이 통과했다(`mac-drawing-style-boundary.log`, 새 함수2개/매개변수 사례3개). 이 추가 수정의 새 후보/패키지와 해당 입력 해시를 연결하고, 실제 재생 중 프레임 진행·재생 중 실패/취소 및 늦은 첫 PTS의 호환성을 확인해야 한다.

Windows 어댑터 수치를 실제 Windows 통과로 확대하지 않는다. 과거 Mac135 내부 검사는 새 설치본·OS 파일 패널 검수의 대체물이 아니다. 이후 소스가 바뀌면 관련 검사와 실제 후보의 입력 해시를 다시 연결한다. 실패한 로그도 삭제하지 않고 최종 성공과 구분해 로컬 QA에 보존한다.

출력 파일의 충돌 방지는 독점 생성으로 한다. 하드링크 발행을 지원하지 않는 파일시스템의 복사 실패는 공용 대상 이름을 자동 삭제하지 않고 **미완료 출력 경로**를 오류로 알린다. 이미 끝난 PDF와 이미지 출력도 별도로 보고한다. 사람은 해당 파일이 자기 미완료 결과인지 확인한 뒤 직접 정리할 수 있다.

Windows의 없는 명시 글꼴은 이름을 보존하고 미리보기에 알리며, 설치된 글꼴을 사용자가 적용하기 전까지 글자 출력은 거부한다. Mac은 없는 명시 글꼴을 시스템 글꼴로 대체하는 기존 동작이 있어 양 OS 출력이 다를 수 있다. 기본/일반 글꼴 별칭은 각 OS의 실제 글꼴로 해석되므로 자형 차이가 남는다. 글자 박스·줄바꿈·가로 맞춤·배경은 계약대로 처리하되 실제 공통 글꼴/두 OS 출력 검수가 남아 있다.

HEIC 출력은 편집한8-bit SDR 픽셀만 새로 인코딩하며 기본 alpha 정책은 보존이다. 흰 배경 합성은 명시 옵션이다. 원본 thumbnail·다른 image item·비-alpha auxiliary·EXIF/XMP를 복사하지 않는 정책과 encoder 실패 시 조용히 JPEG/다른 chroma로 대체하지 않는 경로는 구현했으나, 실제 decoder/encoder로 byte 재열기를 확인하지 못했다. HEIF 사진의 HDR/PQ/HLG는 잘못된 sRGB 재표시를 피하도록 명시 거부 중이다. 영상 HDR에는 같은 guard나 톤매핑이 확인되지 않았으며 실제 PyAV 색/transfer/bit-depth와 Mac SDR preview 대비 검증·수리는 필수 미완료 작업이다. HEIC/HDR을 지원 범위에서 제외한 결정은 아니다.

실제 Windows host/Explorer 드롭·OS 패널·codec/plugin·native encoder·설치·사용자 실행은 미검증이다. 운영 Mac0.7.2는 교체하지 않았다. PowerShell/Inno Setup 실행과 실제 portable ZIP/installer EXE 생성도 미검증이며, exact dependency binary/source/NOTICE 검수 자료가 완성되지 않으면 포장 스크립트가 배포물을 만들지 않도록 막는다. 준비된 스크립트·CI 파일은 실제 Windows 빌드/설치/공개 증거가 아니다.

필요한 환경·설치 승인·실제 OS 절차는 별도 안내한다. 새 도구·운영 설치 교체·원격 공개를 이 문서의 ‘준비’로 승인 처리하지 않는다.

2026-10-02 후속 Mac 내부 검증: 현재 제품 소스의18묶음135건을 `mac-regression135-source-linked.json`에 연결했다. 전체 한 프로세스 시도는9묶음 완료 후 마지막 run summary 없이 exit0으로 끝나 미완료로 기록했고, 전용Portable26 및 나머지8묶음44건의 완료를 각각 확인했다. 100ms/500ms native gap은 추가 강화 검사에서 실제 첫 CGImage/미리보기 meanRGB90.46/90.48로 검은 빈 프레임 통과가 아님을 확인했다. 이 추가 검사 파일 변경도 별도로 보존한다.

`native-heic-alpha-probe-556DFE17-6F9B-42D9-BE7C-F36261920A75/report.json`은 Mac 실제 ImageIO HEIC 출력2사례의 alpha0/128/255·EXIF1/6·sRGB/P3·치수/원본 메타데이터 제거 및 원본 SHA 보존을 확인했다. 이는 Mac과 Windows codec 색상 일치나 HDR, 모든 HEIF auxiliary 검수의 대체물이 아니다. `video-leading-gap-export-probe-3031B18F-A31F-4DBA-A98F-1359D0F40126/report.json`의 500ms gap 출력은 원래 길이1.5초·decoded13프레임의 모든 PTS·빈 구간을 보존했다. 오디오 없는 fixture라 오디오 유지의 추가 증거는 아니다. 재인코딩 픽셀 차이도 보고서에 남았다.
