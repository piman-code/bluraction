# 구현·검증 상태

2026-10-02 개발 중간 기록이다. 전체 Mac·Windows 공개 목표는 미완료다. 검수된 소스 `efc3fce6bd78ff4dcea4d9897a664471865a2f08`까지 GitHub `codex/multipage-document-blur` 개발 브랜치에 공개했다. 최종 태그·Release·설치 파일은 공개하지 않았다. 운영 Mac은 0.7.2/build18 그대로다. 새 Mac 소스 후보는 0.8.0/build19, Windows 소스는 0.8.0.dev1이다.

이 문서의 QA 경로는 비공개 로컬 증거 참조다. 전체 QA·빌드·백업·사용자 원본을 공개 저장소에 포함하지 않는다. 공개 검수 자료는 합성 파일과 필요한 결과만 별도로 선별하고 경로·민감정보를 검토해야 한다.

‘내부 검사’는 합성 원본·직접 API·AppKit/Qt 객체를 사용한 검사다. 실제 Finder/Explorer 드롭, OS 파일 패널, 깨끗한 해당 OS 설치·사용자 실행을 뜻하지 않는다. Windows 어댑터의 로컬 실행 호스트는 macOS arm64다. 첫 실제 GitHub CI는 Windows Server2025 x64에서 실행됐다. Windows10/11 데스크톱 설치·사용자 검수는 아직 확인되지 않았다.

### 이전 영상 프로젝트의 임시 시간축 보호
