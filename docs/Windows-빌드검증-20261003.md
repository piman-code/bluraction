# Windows 빌드 검증 — 2026-10-03

현재 Mac 운영 앱 0.7.2와 Mac 소스는 보존한다. 대상 검수 PC는 사용자 확인 기준 Windows 11 x64다. 학교 PC에는 설치 후보와 합성 자료를 전달하며 개발 도구 설치를 요구하지 않는다.

## 이번에 고친 것

- Windows 빌드 서버에서 받은 라이브러리 17개의 이름·버전·SHA-256과 실제 Python 환경을 연결해 기록한다. 원본 다운로드 주소·휠 파일·사용자 경로는 이 보고서에 넣지 않는다.
- setuptools 내부에 포함된 하위 라이브러리 정보를 최상위 패키지 정보로 잘못 판단하는 문제를 수정했다.
- Python 2/3 겸용 패키지의 호환 태그를 대안으로 처리한다. 잘못된 태그·지원하지 않는 패키지는 계속 거부한다. 이 구분은 [PyPA wheel 명세](https://packaging.python.org/en/latest/specifications/binary-distribution-format/)와 실제 파일로 확인했다.
- Windows 기본 문자 인코딩에서도 한글 인자 검사 결과를 온전히 전달하도록 검사 도구를 수정했다.
- Windows 줄바꿈 때문에 정상 완료 로그를 실패로 읽던 문제를 수정했다. 원본 로그와 해시는 그대로 보존한다.
- **Windows에서 Alt+방향키로 항목이 움직일 수 있는 문제를 수정했다.** Qt 보수 연산에 의존하지 않고 정수 마스크로 허용 키를 확인한다. 캔버스 이벤트와 실제 이동 처리에 같은 규칙을 적용한다.

## 실제 Windows 증거

1. [입력 검증 실행](https://github.com/piman-code/bluraction/actions/runs/37104657719): 실제 Windows x64 CPython 3.14.7과 wheel 17개의 해시를 확보했다. 이후 한글 출력 검사에서 실패했으므로 전체 통과는 아니다.
2. [편집 검사 실행](https://github.com/piman-code/bluraction/actions/runs/37105118810): 패키징·검사 실행기 수리 후 Windows 편집 410개 중 단축키 1개가 실패했다. 29묶음 중 28묶음이 통과했고 나머지 목록은 실행 중단으로 미검증이었다.
3. [단축키 수정 확인](https://github.com/piman-code/bluraction/actions/runs/37105603411): 커밋 `1de757acb4adb6f3029640cc630dbd51966e21b2`에서 해당 19개가 실제 Windows로 통과했다. 전체 목록 검사가 아닌 선택 검사다.

Windows 관측값: 허용 마스크 100663296, Alt 134217728, 기존 Qt 보수 33554431, 기존 Alt 차단 결과 0. 수정한 정수 차단 결과는 134217728이었다. 같은 자료의 Mac Qt 보수 값은 4194303999였다. 따라서 해당 문제는 Windows에서 실제로 확인한 플랫폼 차이다.

4. [수정본 전체 회귀](https://github.com/piman-code/bluraction/actions/runs/37105719040): 같은 `1de757a`에서 GitHub Windows 2025 x64 실행기 사용. 편집·미디어 전체 목록 **36묶음 534개 통과, 실패·오류·skip 0개**, `actualWindows=true`, `fullInventoryRequested=true`, `inputsUnchanged=true`. 필수 HEIF/PDF backend 9개도 통과했지만 전체 목록과 겹치므로 합계에 더하지 않는다. 학교 Windows 11의 설치·화면·파일 패널 검수를 대신하지 않는다.

## 설치본과 남은 작업

이 결과는 설치 EXE 제작이나 학교 PC 사용 검수를 뜻하지 않는다. 실제 포함 DLL·코덱·대응 소스와 라이선스 자료 연결, 검토한 번들 생성, 설치 EXE의 해시·서명 상태 확인이 남아 있다. `pending` 검토 기록을 임의로 승인 상태로 바꾸지 않는다.

운영 Mac 앱 교체·컴퓨터 사용 자동화·학교 자료 업로드는 하지 않았다. 원격에는 검토한 소스와 합성 검사 자료만 보냈다. 개발 중 중복 자동 검사를 억제하고 명시한 검사만 실행했으며, 최초 푸시로 자동 시작된 중복 PR 두 건은 취소했다. 최종 공개·병합에는 전체 필수 검증이 별도로 필요하다.
