# 변경 기록

## 0.8.0 개발 중 — 공개 릴리스 아님

Mac 후보는 build19, Windows Qt 소스 후보는0.8.0.dev1이다. 전체 두 OS 설치·사용 검수와 공개 승인은 아직 완료되지 않았다. 아래 구현 목록은 실제 해당 OS 검수 통과를 뜻하지 않는다.

- 기존 Mac AppKit 앱을 유지하면서 Windows 한국어 Qt 앱·공통 프로젝트 계약·합성 회귀 자료·플랫폼별 빌드/포장 경로를 추가했다.
- v1 단일 미디어 프로젝트의 선택적 SHA-256과 v2 페이지별 SHA-256을 검증하고, 외국 OS의 경로를 명시적으로 다시 연결하도록 했다. 기존 편집·확장 필드·페이지 순서를 보존하며 모호한 좌표나 지원하지 않는 형식을 자동 변환하지 않는다.
- 후보 미디어 열기·프로젝트 열기를 준비한 뒤 확정하도록 바꿨다. 실패·취소·늦은 완료·원본 변경에서는 현재 dirty 편집과 기록을 보존한다. Windows의 긴 파일 검사·열기·저장은 QThread에서 처리한다.
- Mac의 메타데이터만 읽히는 손상 영상이 기존 편집을 교체하던 문제를 실제 프레임 검증으로 수정했다. 정상 영상의 선행 빈 구간을 유지하며 실제 첫 CGImage와 표시 PTS를 사용한다. 생성·기록점·기간·지우개는 표시 프레임 시각을 사용해 탐색 시각 반올림으로 새 가림이 사라지던 문제도 수정했다.
- 큰 효과 값과 소수 굵기·채우기를 다른 속성 변경이 덮어쓰지 않도록 했다. Windows 가리기 영역·그림 혼합 선택은 종류별 유효 필드만 수정한다.
- Windows에 페이지별 PDF·이미지 편집/복사·레이어·그룹·시간 기반 지우개·키프레임 편집·프로젝트 템플릿과 PNG/JPEG/TIFF/PDF 출력 경로를 구현했다. PyAV 영상·CSRT 추적·pypdf 이전 PDF 기하·pillow-heif HEIC 경로는 실제 의존성과 Windows 검증이 남아 있다.
- Mac PDF/이미지는 최종 원본 해시 확인 뒤 발행 직전에도 취소를 확인한다. Windows 효과·그리기는 선형 색과 premultiplied alpha 합성·WindingFill로 맞췄으며 비동기 미리보기의 후속 검수는 진행 중이다.
- 파일 이름·원본 지문·취소와 별도 새 출력 발행을 검사하고, Windows 장치명/ADS/모호한 경로를 거부한다. 이미 완성된 출력과 미완료 출력은 구분해 알린다.

## Mac 0.7.2/build18 — 운영 기준

2026-10-01 검수 후보를 사용자가 승인해 운영 앱에 적용한 기준이다. 다중 PDF·이미지의 독립 편집과 저장/재열기, 평탄화 PDF/이미지별 PNG, crop/회전/화면맞춤, 원본 지문 및 기존6결함 수리의 검수 기록이 있다. 실제 Finder 드롭과 OS 파일 패널·새 설치본 사용자 실행은 당시 내부 검사로 대체하지 않았다.

0.7.1/0.7.0/0.6.0 복구본과 사용자 원본을 보존한다. 새 Mac 운영 설치는 검수한 구체 후보와 복구안에 대한 별도 승인을 확인한 뒤 적용한다.

최신 완료/미완료 증거는 [검증 상태](검증-상태.md), 실제 사용자 절차는 [OS 검수](실제-OS-검수.md), 설치 복구는 [Mac 안내](Mac-설치와-복구.md)를 확인한다.
