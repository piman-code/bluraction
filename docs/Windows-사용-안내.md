# Windows 사용 안내 초안

현재 대상은 한국어 Qt 개발 후보 `0.8.0.dev1`입니다. 아직 실제 Windows 설치·실행 검수와 공개 릴리스가 완료되지 않았습니다. 아래 설명은 구현된 메뉴를 기준으로 하며, 기능별 검증 범위는 [검증 상태](검증-상태.md)를 확인하세요. 설치 파일이 준비되면 실제 검수 버전·다운로드·해시를 별도로 표시합니다.

## PDF·이미지 편집

1. 위쪽 **파일 열기…**(Ctrl+O)에서 PDF 또는 여러 이미지를 선택합니다. 가운데 캔버스에 원본 비율로 맞춰 표시합니다. 영상은 한 파일씩 엽니다. PDF와 이미지를 섞으면 전체 200쪽까지입니다.
2. 위쪽 도구에서 가릴 영역의 사각형·타원·자유형을 고르고 캔버스에 만듭니다. 오른쪽 **가리기 방식**에서 블러·모자이크·단색과 강도, 경계 부드럽게, 색을 바꿉니다.
3. 선·펜·사각형·타원·화살표·글자 도구로 그립니다. 오른쪽에서 그림·글자 색, 선 굵기, 채우기를 조절합니다. 여러 줄 글자는 내용과 글꼴을 입력한 뒤 **선택 글자 내용·글꼴 적용**으로 수정합니다.
4. 아래 이전·다음으로 페이지를 바꿉니다. 각 페이지의 편집은 독립적입니다. **현재 페이지 작업을 모든 페이지에 적용…**은 확인 후 다른 페이지의 편집을 대체합니다. 복사 후 페이지마다 따로 수정할 수 있습니다.
5. 오른쪽 **레이어 (위가 앞)** 목록에서 항목을 골라 이름·숨기기·잠금을 바꿉니다. 여러 항목을 선택한 뒤 편집 메뉴에서 그룹·그룹 풀기·복제·순서를 조절합니다. 그림은 가리기 영역 위에 그려집니다.
6. 지우개는 **부분 지우기** 또는 **닿은 항목 삭제**를 선택하고 대상·크기를 조절합니다. Ctrl+Z로 실행취소, Ctrl+Shift+Z로 다시 실행합니다.

## 영상과 시간 편집

아래 재생·탐색으로 시점을 옮깁니다. 항목을 선택해 오른쪽 시작·끝 초를 바꾸고 **구간 적용**을 누릅니다. **움직임 기록**을 켜고 항목을 이동하거나 **현재 위치 기록**으로 위치를 남깁니다. 기록 목록에서 시점을 고르고 **기록 시각 적용** 또는 **선택 기록 삭제**로 고칩니다.

**선택 항목 자동 추적**은 선택한 항목을 현재 구간에서 추적합니다. **취소**로 작업을 중단할 수 있습니다. 지우개의 **영상: 지금 시점부터 지우기**는 이전 시점의 그림을 유지합니다. 영상 디코딩·출력·CSRT 자동 추적은 실제 코덱 의존성과 Windows 검수가 남아 있어 현재 완료로 표시하지 않습니다.

## 저장·다시 연결·내보내기

**프로젝트 저장…**(Ctrl+S)은 편집 정보를 새 `.bluraction` 파일에 저장합니다. 원본 파일과 실행취소 기록은 프로젝트에 포함되지 않습니다. **프로젝트 열기…**(Ctrl+Shift+O)로 다시 엽니다. 다른 OS나 폴더로 옮긴 프로젝트는 **원본 다시 연결…**에서 직접 파일을 선택합니다. 저장된 SHA-256과 다른 원본은 연결하지 않습니다. 지문 없는 이전 프로젝트는 원본을 직접 확인해야 합니다.

현재 개발 후보는 일부 영상의 시간축 호환 검토가 끝나지 않았습니다. 시간 원점이 정확한 0초로 확인되지 않은 영상에 구간·이동 기록·시간 지우개가 있으면 프로젝트 열기·가져오기·템플릿 적용·저장을 중단하고 안내합니다. 원본과 이전 프로젝트, 현재 편집은 유지합니다. 기존 시각을 임의로 이동하거나 원본 프로젝트를 덮어쓰지 마세요. 이는 완성 전 임시 보호이며 해당 영상 기능의 지원 완료를 뜻하지 않습니다.

다른 컴퓨터에 같은 글꼴이 없으면 이름을 유지하고 안내합니다. 해당 컴퓨터에 설치된 글꼴을 직접 적용한 뒤 출력하세요. 자동 대체한 결과를 같은 글꼴로 간주하지 않습니다. 이전 PDF 편집의 회전·crop 좌표가 영향을 받으면 열기를 거부하고 기존 작업을 유지합니다. 원본과 예전 프로젝트를 보존한 채 새로 편집해 위치를 확인하세요.

**내보내기…**(Ctrl+E)는 원본과 다른 새 결과를 만듭니다. 문서 묶음은 평탄화 PDF와 이미지별 PNG를 출력합니다. PDF의 원본 검색 가능한 텍스트·숨은 객체는 새 PDF에 복사하지 않습니다. 단일 이미지는 선택한 지원 형식으로 출력합니다. HEIC 실제 코덱 검수와 HDR 처리는 아직 남아 있습니다. 영상은 실제 코덱 환경과 결과 길이·프레임·오디오를 확인한 후 지원 범위를 확정합니다.

기존 파일·원본 이름은 덮어쓰지 않습니다. 작업 중에는 새 입력과 편집을 잠시 막고 취소 버튼을 유지합니다. 문서 묶음에서 이미 완성된 일부 결과는 후속 저장 취소 후에도 남을 수 있습니다. 완료·부분 결과 안내를 확인하세요. 출력의 모든 페이지·이미지와 영상의 대표 프레임을 직접 확인한 뒤 사용하세요.

## 단축키

| 키 | 동작 |
| --- | --- |
| Ctrl+O | 파일 열기 |
| Ctrl+Shift+O | 프로젝트 열기 |
| Ctrl+S / Ctrl+E | 프로젝트 저장 / 내보내기 |
| Ctrl+Z / Ctrl+Shift+Z | 실행취소 / 다시실행 |
| Ctrl+D / Delete | 선택 항목·그룹 복제 / 삭제 |
| Ctrl+Shift+I | 프로젝트 항목 가져오기 |

Mac의 설치·복구는 [Mac 안내](Mac-설치와-복구.md), Windows 빌드와 의존성 검토는 [플랫폼 빌드 상태](플랫폼-빌드-상태.md)를 따릅니다. 실제 Explorer 드롭·파일 패널 동작은 내부 검사로 대신하지 않습니다.
