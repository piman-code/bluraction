# 실제 OS 검수

자동·내부 검사와 별도로 확인하는 사용자 실행 기록이다. 컴퓨터 사용 권한,
접근성, 화면 기록, OS 입력 자동화는 사용하지 않는다. 개인 자료 대신
`shared/fixtures/manual-os/`의 합성 PDF·이미지 네 개를 쓴다.

## 현재 Mac 설치본 0.7.2/build18 — 약 5분

1. `/Applications/BlurAction.app`을 직접 실행한다. 프로젝트 루트의 예전
   `BlurAction.app`과 구분한다. 앱의 버전 표시가 0.7.2인지 확인한다.
2. Finder에서 `synthetic-01.png`, `synthetic-02.png`, `synthetic-03.png`을 함께
   캔버스로 끌어 놓는다. 페이지가 3개이고 모든 이미지가 위·아래까지 보이는지 확인한다.
3. 첫 페이지에 단색 사각형 하나를 만들고 현재 작업을 모든 페이지에 적용한다.
   둘째 페이지에 타원 하나만 추가한다. 첫째·셋째 페이지는 바뀌지 않아야 한다.
4. ⌘S의 실제 파일 패널로 새 검수 폴더에 `Mac-이미지-검수.bluraction`을 저장한다.
   프로젝트를 다시 열어 페이지별 항목과 위치가 그대로인지 확인한다.
5. ⌘E의 실제 저장 패널로 `Mac-이미지-검수.pdf`를 출력한다. PDF 3페이지와
   새 `_images` 폴더의 PNG 3개를 직접 열어 가림 위치·그림·상하단을 확인한다.
6. Finder에서 `synthetic-three-pages.pdf`와 `synthetic-01.png`를 함께 드롭한다.
   총 4페이지가 열려야 한다. 새 프로젝트와 PDF를 저장하고 다시 열어 확인한다.
7. 기존 결과 이름으로 다시 저장을 시도한다. 기존 결과를 덮어쓰지 않아야 한다.
   취소를 누른 뒤 기존 결과와 원본 파일이 남아 있는지 확인한다.

저장한 폴더 경로와 아래 결과를 알려 주면 출력 파일·원본 지문을 대조한다.
개인 문서나 개인정보를 검수 폴더에 넣지 않는다.

```text
OS/CPU:
앱 경로·버전:
실제 Finder 이미지 묶음 드롭: 통과/실패 + 관찰
실제 Finder PDF+이미지 드롭: 통과/실패 + 관찰
실제 파일 패널 저장·재열기: 통과/실패 + 관찰
페이지별 독립 편집·상하단·출력 PDF/PNG: 통과/실패 + 관찰
기존 결과 보존·취소: 통과/실패 + 관찰
검수 결과 폴더:
```

## 새 Mac 비공개 후보0.8.0/build19 — 미검수

현재 내부 검수에 연결한 후보는 `.build/candidates/BlurAction-0.8.0-20261002-053145.app`이다. 운영 `/Applications/BlurAction.app`을 교체하지 않았다. 이 후보의 실제 사용자 실행·Finder·파일 패널은 아직 미검증이며, 위 운영0.7.2의 관찰을 새 후보 통과로 옮기지 않는다.

사용자 검수 시 기존 작업을 별도 프로젝트로 저장하고 앱을 종료한 뒤, 해당 후보 경로를 직접 열어 버전0.8.0/build19를 확인한다. 위7단계를 별도 `Mac-0.8-검수` 폴더에서 수행한다. 파일 충돌·취소 후 기존 결과가 보존되는지와 다시 실행해 같은 프로젝트가 열리는지도 확인한다. 후보의 실제 실행을 승인한 운영 설치 교체로 취급하지 않는다. 다른 Mac의 기본 Gatekeeper 판정은 rejected이고 Developer ID·공증이 없으므로 깨끗한 OS 설치 검수·일반 공개 배포 수락은 별도로 남는다. 보안 설정을 끄지 않는다.

영상은 합성 자료의 일반 영상과 선행 빈 구간 영상을 각각 열고 재생·일시정지·앞뒤 탐색을 확인한다. 표시된 프레임에 새 단색 가림을 만들면 즉시 그 프레임이 가려져야 한다. Undo/Redo·저장·재열기 뒤 위치/기간이 유지돼야 한다. 시간 지우개·기록점 수정·추적/취소 후 내보낸 길이와 전체 프레임 PTS·오디오는 사용자 관찰과 별도 출력 검사를 함께 기록한다. 영상 자료와 최종 출력 검수는 별도 안내하며 개인정보가 들어간 원본을 쓰지 않는다.

## Windows 패키지

Windows 패키지는 아직 검수 후보로 완성되지 않았다. 실제 Windows에서 빌드된
설치 파일과 SHA-256이 준비되면 버전·설치/복구 경로를 포함한 절차를 추가한다.
Mac에서 Qt를 실행한 결과나 CI 빌드만으로 Windows 설치·사용 검수를 통과 처리하지 않는다.
영상 길이·프레임·오디오·대표 프레임, 자동 추적·취소 및 양방향 프로젝트
재연결 검수는 두 OS의 최종 패키지 단계에서 추가 수행한다.
