# Mac 설치와 복구

이 문서는 macOS 14 이상 arm64 후보의 수동 설치 안내다. 새 후보의 실제 깨끗한 Mac 설치·사용자 검수는 아직 완료되지 않았다. 현재 개발 후보는 0.8.0/build19이며 운영 0.7.2/build18을 자동 교체하지 않는다. Intel Mac·다른 OS 버전은 별도 검증 전 지원 완료로 표시하지 않는다.

다운로드한 ZIP 또는 DMG의 SHA-256을 제공한 `SHA256SUMS.txt`와 비교한다. DMG와 ZIP에는 같은 앱, MIT 라이선스, 이 안내만 포함한다. 프로젝트와 사용자 원본은 포함하지 않는다. 앱은 현재 로컬 ad-hoc 서명이다. Developer ID 서명·Apple 공증을 완료한 배포물이 아니다. 보안 설정을 끄거나 인증서를 임의로 신뢰시키지 않는다.

1. 기존 BlurAction에서 작업을 새 프로젝트 파일로 저장하고 종료한다. 원본·기존 프로젝트·출력은 앱 폴더와 별도로 보존한다.
2. 검수 후보는 별도 폴더에 두고 직접 실행할 수 있다. 버전이 표시되는지 확인한다. 기존 `/Applications/BlurAction.app`과 다른 앱이다.
3. 운영 앱 교체는 해당 후보의 구체적인 설치 승인을 받은 뒤 한다. 기존 앱을 버전과 날짜가 있는 복구 폴더에 보관한 후 새 앱을 `/Applications`로 복사한다. 기존 앱 위에 덮어쓰거나 복구본을 삭제하지 않는다.
4. 합성 PDF·이미지 묶음을 실제 Finder로 드롭하고 파일 패널로 새 프로젝트 저장·재열기·내보내기를 확인한다. 영상은 길이·오디오·프레임·시간 편집과 추적/취소를 확인한다. 단순 실행만으로 최종 검수 완료가 아니다.

복구할 때는 작업을 저장하고 새 앱을 종료한다. 새 앱도 별도 폴더에 보관하고 이전 앱을 `/Applications/BlurAction.app`으로 복원한다. 프로젝트와 원본을 삭제하지 않는다. 이전 버전이 새 프로젝트의 기능을 이해한다고 가정하지 말고 별도 이름으로 저장한 이전 프로젝트를 연다.

이 작업 위치의 기존 복구본은 `.build/backups/`에 있다. 0.7.1·0.7.0·0.6.0 복구본을 유지한다. 운영 앱은 0.7.2/build18이며 후보 설치·공개 승인 전까지 보존한다.

빌드 후 패키지를 재현하려면 다음을 실행한다. 두 번째 경로는 반드시 존재하지 않는 새 폴더여야 한다. 이 명령은 설치·앱 실행·공증·공개를 하지 않는다.

```sh
./scripts/build_app.sh --build-only --no-install
bash scripts/package_mac_candidate.sh "$PWD/.build/BlurAction.app" "$PWD/.build/new-mac-package"
```

프로젝트 저장은 원본 지문과 경로를 기록하며 원본 미디어를 포함하지 않는다. 다른 OS로 가져갈 때 같은 원본 파일을 따로 복사하고 앱의 재연결 절차에서 지문을 확인한다. 원본이 달라졌거나 이전 PDF 기하가 안전하지 않으면 저장된 가림 위치를 자동 적용하지 않는다.
